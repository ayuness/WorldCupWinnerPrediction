# 🏆 Predicción del Campeón del Mundial FIFA

## 📌 Descripción
Proyecto de Data Science que combina **Machine Learning** y **Simulación Monte Carlo** para predecir el campeón del próximo Mundial de la FIFA. El modelo predice el resultado de cada partido de forma individual y simula el torneo completo —desde la fase de grupos hasta la final— miles de veces, obteniendo una estimación probabilística del ganador.

---

## ⚙️ Pipeline

### 1. 📥 Recopilación de datos
Búsqueda y obtención de datos históricos de la Copa del Mundo, incluyendo resultados de partidos, rankings y estadísticas por selección.

### 2. 📊 Análisis Exploratorio de Datos (EDA)
Exploración de variables, distribuciones y patrones clave que influyen en el rendimiento de las selecciones a lo largo del torneo.

### 3. 🧹 Limpieza y Estructuración
Tratamiento de valores faltantes, corrección de inconsistencias y preparación del dataset para el proceso de modelado.

### 4. 🛠️ Ingeniería de Variables (Feature Engineering)
Definición y construcción de variables relevantes para conformar el dataset maestro del proyecto.

### 5. 🎯 Selección de Variables (Feature Selection)
Identificación de las variables con mayor poder predictivo para optimizar el rendimiento del modelo.

### 6. 🤖 Entrenamiento del Modelo
Entrenamiento de un modelo de clasificación capaz de predecir el resultado de un partido entre dos selecciones (victoria, empate o derrota).

### 7. ✅ Evaluación y Validación Cruzada
Medición del desempeño del modelo mediante métricas de clasificación y validación cruzada para garantizar su generalización.

### 8. 🎲 Simulación Monte Carlo
Simulación del torneo completo partido a partido, repitiéndose miles de veces para estimar la probabilidad de campeonato de cada selección.

---

## 🎯 Resultado esperado
Una estimación probabilística del campeón más probable del próximo Mundial, respaldada por miles de simulaciones del torneo. El resultado incluye un ranking de selecciones ordenado por su probabilidad de ganar, ofreciendo una perspectiva basada en datos sobre quién levantará la copa.
